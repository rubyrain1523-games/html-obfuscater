# Veil HTML Obfuscator

A single-file, client-side HTML obfuscator and decoder. It has no dependencies and does not upload your files.

## Use it

- Open `index.html` directly in a modern browser, or publish the repository with GitHub Pages.
- Paste HTML into the source pane or choose an `.html` file, then select **Obfuscate HTML**.
- Download the result. The generated `.html` opens and runs like a normal HTML file, including from a local files app.
- To restore the source, switch to **Deobfuscate**, paste or open a Veil-generated file, and select **Deobfuscate HTML**.

Each run uses a new random byte key, payload chunking, and runtime variable names, so the generated wrapper changes between runs.

## Limitations

This is casual-observer obfuscation, not encryption or copy protection. The HTML is recoverable by anyone who can inspect or run the file. Do not put secrets in client-side HTML or scripts. The decoder supports files generated by this tool; it is not a general-purpose deminifier or decoder for other obfuscators.
